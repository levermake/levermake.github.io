# LEVERMAKE

A cinematic, static, black-and-white website for Levermake.

## Design

- Renaissance/public-domain artwork used as animated atmospheric layers
- Scroll-driven artwork movement
- 3D-style wireframe overlays
- Editorial typography
- Custom cursor
- Magnetic interactions
- Full-screen navigation
- Responsive mobile layout
- Reduced-motion support
- No framework
- No build step
- GitHub Pages compatible

## Artwork

The artwork URLs currently point at The Metropolitan Museum of Art's Open Access image infrastructure. The Met states that public-domain artwork images are available for unrestricted use under CC0. Verify the current rights metadata for any image before changing or adding artwork.

## Deploy

Upload the repository contents to GitHub and enable GitHub Pages.

## Replace artwork

Edit the `.painting-a`, `.painting-b`, and `.painting-c` background-image URLs in `styles.css`.

## Customize

- `index.html` — content and links
- `styles.css` — visual design
- `app.js` — interaction and scroll behavior
